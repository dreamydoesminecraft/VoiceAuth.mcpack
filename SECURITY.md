# Security Policy — VoiceAuth
Maintained by **Dreamy Does Minecraft**  
(Independent creator operating as **Dreamy’s Entertainment Production**)

VoiceAuth is a Minecraft Bedrock modpack that includes scripting, UI assets, and verification logic.  
To protect the project, users, and the creator, please follow the security guidelines below.

---

## 🔐 Supported Versions

Security reports are accepted for:

- The latest public release of VoiceAuth  
- The latest development version on GitHub  

Older versions may not receive fixes.

---

## ⚠ Reporting Security Issues

If you discover a vulnerability, exploit, or security concern related to:

- Script API behavior  
- Verification logic  
- Packet handling  
- Unauthorized access  
- Code injection  
- Reverse engineering attempts  
- Redistribution abuse  
- Impersonation of Dreamy Does Minecraft  

You **must report it privately**.

### 📧 Contact for Security Reports
Send all security‑related reports to:

**officialdydmc.msc@gmail.com**

Please include:

- A clear description of the issue  
- Steps to reproduce  
- Any screenshots or logs (if applicable)  
- Whether the issue affects gameplay, verification, or user safety  

I will review the report personally.

---

## 🚫 Do Not

You are **NOT** allowed to:

- Publicly disclose vulnerabilities before they are fixed  
- Attempt to exploit or weaponize any discovered issue  
- Reverse‑engineer, decompile, or bypass VoiceAuth systems  
- Modify or redistribute the modpack to test exploits  
- Use vulnerabilities to harm players, servers, or the creator  

Violations may result in:

- DMCA takedowns  
- Copyright claims  
- GitHub abuse reports  
- Platform‑level enforcement  

---

## ✔ Responsible Disclosure

If you report a security issue responsibly:

- You will be credited (optional)  
- You will not face penalties  
- Your report will be handled respectfully and privately  

As a solo indie creator, I appreciate all responsible reports.
